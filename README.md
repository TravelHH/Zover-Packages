# Zover Package Builder – صانع الباكيدجات

برنامج لعمل باكيدجات السفر لشركة **زوفر العالمية للسفر والسياحة**. بيشتغل من غير نت بعد أول فتحة، على الموبايل والكمبيوتر.

🔗 **الرابط:** https://travelhh.github.io/Zover-Packages/

## المميزات
- ٤٠ وجهة جاهزة، وكل وجهة فيها المدن والليالي والبرنامج اليومي
- الطيران: إدخال يدوي أو لصق شاشة أماديوس
- الفنادق: لحد ٤ خيارات، والسعر للغرفة في الليلة
- خدمات مشمولة واختيارية، وتتحسب للفرد أو للمجموعة
- التسعير: هامش ربح، وضريبة القيمة المضافة، وتقريب السعر، وتسكين
- المخرجات: عرض PDF وصورة JPEG للسوشيال، بالعربي أو الإنجليزي
- مكتبة على الجهاز، مع تصدير واستيراد الباكيدجات كملفات

## التثبيت على الموبايل
افتح الرابط ← قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.

## للمطورين
الكود المصدري موجود في `source/`. لبناء `index.html`:
```
cd source && npm i @fontsource/tajawal @fontsource/outfit html-to-image && python3 build.py
```
(لازم تظبط المسارات اللي في `build.py`).
