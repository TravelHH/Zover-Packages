# زوفر ستوديو – عروض الباكيدجات

بتختار الباكيدج وتكتب السعر والمواعيد، وبيطلعلك:
- **صورة شاملة** للباكيدج، فيها صورة لكل مدينة
- **مجموعة صور** للسوشيال: غلاف، وصورة لكل مدينة، والبرنامج اليومي، والأسعار
- **بروشور PDF**: غلاف، وصفحة لكل مدينة، وصفحة الأسعار والشروط

🔗 https://travelhh.github.io/Zover-Packages/

- **الثيمات:** زوفر، وفاخر، ومجلة، وحيوي
- **المقاسات:** مربع 1:1، وطولي 4:5، وستوري 9:16، وA4 للـ PDF
- **مكتبة الصور:** في فولدر `img/<city>/`، والصور من Pexels برخصة تسمح بالاستخدام التجاري من غير ذكر اسم المصوّر
