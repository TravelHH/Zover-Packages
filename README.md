# Zover – صانع عروض الباكيدجات

بتكتب بيانات العرض، وبيطلعلك **صورة إعلان واحدة** جاهزة للسوشيال والواتساب، بهوية زوفر.

🔗 **الرابط:** https://travelhh.github.io/Zover-Packages/

## الاستخدام
1. اختار التصميم والمقاس والألوان
2. اكتب الوجهة وعدد الليالي والمواعيد، أو اختارها من الـ ٤٠ وجهة الجاهزة
3. ارفع لحد ٤ صور
4. اكتب السعر أو الأسعار (مثلاً 4 و5 نجوم)
5. اختار اللي البرنامج بيشمله
6. اضغط **تحميل** أو **واتساب**

- **التصاميم:** كولاج صور، صورة كاملة، بطاقة
- **المقاسات:** مربع 1:1، طولي 4:5، ستوري 9:16

البرنامج بيشتغل من غير نت بعد أول فتحة. ولتثبيته على الموبايل: قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.

## للمطورين
الكود في `source/`. للبناء:
```
cd source && npm i @fontsource/tajawal @fontsource/outfit html-to-image && python3 build.py
```
